# NocturneTXT — Plain-Text Audiobook Release Tracker (v1.7)

A lean, native Android app inspired by [Plain Text Sports](https://plaintextsports.com/) with official [Dracula and Alucard](https://draculatheme.com/spec) themes for tracking upcoming Audible releases (`api.audible.com/1.0/catalog/products`).

## Key Highlights in v1.7
- **Whole-Card Tap to Expand (No Info Button Needed)**: Tap anywhere on any book box in `UPCOMING` to toggle its expanded view containing the synopsis, runtime, publisher, and all action buttons (`[ Audible ]`, `[ ABB ]`, `[ Copy ]`, `[ + Cal ]`, `[ DND Book ]`, `[ DND Series ]`).
- **Configurable Collapsed Card Actions Toggle**: In `SETTINGS`, toggle `Always Show Card Actions` `[ ON ]` / `[ OFF ]` if you prefer action buttons visible on collapsed cards like before.
- **Distinct Thumbnails in `TRACKED` Tab**: Followed Authors, Series, Books, and Narrators now display their own framed `52dp` thumbnails in the `TRACKED` tab (automatically resolving author/narrator portraits or distinct catalog covers for each source).
