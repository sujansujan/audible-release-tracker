# NocturneTXT — Plain-Text Audiobook Release Tracker (v1.5)

A lean, native Android app inspired by [Plain Text Sports](https://plaintextsports.com/) with official [Dracula and Alucard](https://draculatheme.com/spec) themes for tracking upcoming Audible releases (`api.audible.com/1.0/catalog/products`).

## Key Highlights in v1.5
- **Renamed to `NocturneTXT` & Headerless Chrome**: The app name is hidden across all working screens for a distraction-free terminal aesthetic and appears exclusively inside the `[ ABOUT ]` page in `SETTINGS`.
- **3-Tab Bottom Navigation (`< UPCOMING | TRACKED | SETTINGS >`)**: `DND` is now integrated directly into the `UPCOMING` filter bar (`[ ALL ] [ SERIES ] [ AUTHOR ] [ NARRATOR ] [ <=30d ] [ RECENT ] [ DND ]`).
- **Tick Option for Direct Manual Add**: Enable or disable `Direct Manual Add Mode` as a standard `[ ON ]` / `[ OFF ]` setting in `SETTINGS`.
- **Monthly Scoreboard Headers (`+=== OCTOBER 2026 (3) ===+`)**: Groups upcoming releases chronologically by month with release counts.
- **`[ RECENT ]` (Last 30 Days) Filter & `[ ✓ Mark Read ]`**: View books released in the past 30 days and update your series read progress with one tap.
- **Followed Source Type Filter & `[ X upcoming ]` Badges**: Filter your followed sources by `[ ALL ] [ SERIES ] [ AUTHOR ] [ NARRATOR ] [ BOOK ]` and see how many upcoming releases each source currently has.
- **One-Tap `[ Copy ]` & Cache Inspector (`[ CLEAR CACHE ]`)**: Copy plain-text release summaries to your clipboard and inspect or clear disk/memory caches in `SETTINGS`.
