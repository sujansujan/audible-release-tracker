# NocturneTXT — Plain-Text Audiobook Release Tracker (v3.0)

A lean, native Android app inspired by [Plain Text Sports](https://plaintextsports.com/) with official [Dracula and Alucard](https://draculatheme.com/spec) themes for tracking upcoming Audible releases (`api.audible.com/1.0/catalog/products`).

## Key Highlights in v3.0 (Share-Sheet ASIN Importer & Full ASCII UI Overhaul)
1. **Android Share-Sheet ASIN & URL Importer (`Intent.ACTION_SEND`)**: Share any Audible book, series, or author link directly from your browser or the Audible app into NocturneTXT. The app automatically parses the 10-character ASIN (`B0...`) or URL slug, fetches live metadata, and opens an inline ASCII import panel with one-tap `[ + Series ]`, `[ + Author ]`, `[ + Narrator ]`, and `[ + Book ]` controls.
2. **Inline ASCII Status Ticker (Zero System `Toast`s)**: Replaced all 11 Android Material `Toast` overlays across `TrackerScreen` and `MainActivity` with a self-dismissing 1dp terminal status bar docked above the bottom thumb bar (`> OK: MAGNET URI COPIED TO CLIPBOARD [ x ]`).
3. **Column-Measured Full-Width ASCII Headers & Frames**: `AsciiSectionHeader` and `AsciiBox` measure the exact character cell width via `rememberTextMeasurer()` to pad headers across the full screen width (`+=== NOVEMBER 2026 (4 RELEASES • 68H 20M) ========+` and `+---[ 2026-11-18 [ T-5d ] • [ NEW ] ]-----------+`).
4. **Dotted-Leader Settings, `[x] ON` Switches & `(*)` Radio Controls**: Converted Settings toggles, theme pickers, and store region selectors to column-aligned dotted leaders (`English Language Only ............ [x] ON`) and ASCII radio controls (`(*) SYSTEM AUTO  ( ) DRACULA  ( ) ALUCARD`).
5. **Expanded Card Boxscore Grid & Character Rules (`AsciiRule`)**: Replaced Material `HorizontalDivider`s and pipe-separated metadata strings inside cards with character rules (`- - - - - -`) and dotted-leader boxscore rows (`Runtime`, `Publisher`, `Edition`, `Matched Source`, `Date Shifted`, `Narrator Alert`).
6. **Stepped ASCII Sync Spinner, Inverse-Video Press Feedback & `[ ABB ]` Quick Filter**: Added a stepped terminal spinner with live source progress (`[\ SYNC 4/7]`), inverse-video button press states, pure ASCII `[x]` checkmarks, a `[ Magnet ]` action button on `[ON ABB]` notifications, and a dedicated `[ ABB (N) ]` filter pill.
